Mind Elixir（代码仓库通常为 ssshooter/mind-elixir-core）是一个高性能、轻量级且开源的 JavaScript 思维导图核心库。它专为开发者设计，旨在让任何前端项目都能快速集成功能完备的思维导图功能。
以下是该项目的核心特点与功能介绍：
1. 核心优势
框架无关性 (Framework Agnostic)： 不绑定任何特定的前端框架（如 React、Vue 或 Angular），可以直接在原生 JavaScript 环境中使用，也极易适配各类现代前端框架。
高性能与轻量： 经过优化，能够流畅处理大规模节点的思维导图，且库的体积非常小。
插件化架构： 拥有高度的可扩展性，支持通过插件机制添加自定义功能。
交互体验友好： 内置了流畅的拖拽、节点编辑、快捷键操作等，并对移动端触摸交互有良好的支持。
2. 核心功能
交互编辑： 支持节点的创建、删除、移动（拖拽）、编辑，以及多选批量操作。
操作历史： 内置撤销（Undo）和重做（Redo）功能。
数据进出口： 支持将导图导出为 SVG、PNG 或 HTML 格式，方便分享与展示。
样式自定义： 允许通过 CSS 变量和内置主题系统对导图的视觉风格进行深度定制。
Markdown 支持： 支持解析 Markdown 内容，方便处理复杂文本。
